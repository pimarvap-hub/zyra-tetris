# ZYRA Tetris 🥤

Тетрис из банок лимонада **ZYRA**.

> ⚠️ Не отправляй ссылку `github.com/...` — это код.  
> Нужна ссылка **`github.io`** — это сама игра.

## Управление
- ← → двигать  
- ↑ / Space — поворот  
- ↓ ускорить  
- C — hold  
- На телефоне — кнопки и свайпы
