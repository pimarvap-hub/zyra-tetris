# ZYRA Tetris 🥤

Яркий тетрис из банок лимонада **ZYRA**.

## Играть онлайн

**https://pimarvap-hub.github.io/zyra-tetris/**

## Локально

Открой `index.html` в браузере или:

```bash
python3 -m http.server 8080
```

## Управление

- ← → двигать
- ↑ / Space — поворот
- ↓ ускорить
- Space — сброс
- C — hold
- На телефоне — кнопки и свайпы
